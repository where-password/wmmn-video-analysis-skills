# 专业视频逆向拆解交接稿

> 这是交给新对话、其他大模型、自己的工作流或剪辑人员的结构化草稿。不要补写未观察到的画面、运镜和转场。

## 本次范围

- 镜头范围：1–5
- 时间范围：约 0.0–25.0 秒
- 全片镜头数：约 12 个
- 草稿阶段：first_pass_reverse_engineering
- 时间码证据：provided

## 首批锚点

- 首个转场：约 5 秒，硬切
- 首个明显运镜：镜头 2，约 6.25 秒，画面前景扩张，疑似推近（不能区分变焦与物理推进）

## 逐镜观察与提示词

### 镜头 1 · 0.0–5.0 秒

- 画面：昏暗房间，桌面上有一台亮着的显示器
- 人物/动作：蓝发角色 / 从屏幕后探出头
- 景别：中景
- 运镜：固定（宿主观察）
- 转场：开场（宿主观察）
- 首尾帧：角色完全躲在屏幕后 → 角色露出半张脸
- 画面提示草案：昏暗房间，蓝发角色从显示器后探出半张脸，中景，屏幕冷光，人物为视觉中心。
- 视频简版草案：昏暗房间，蓝发角色从屏幕后探头，中景，冷色屏幕光，真实角色运动。
- 动作/运镜草案：开拍即探头，从屏幕后缓慢露出半张脸，最后停住，镜头固定。
- 可行性：draft_ready

### 镜头 2 · 5.0–10.0 秒

- 画面：同一房间，桌面出现一块饼干
- 人物/动作：蓝发角色 / 双手捧起饼干
- 景别：中近景
- 运镜：缓推（宿主观察）
- 转场：硬切（宿主观察）
- 首尾帧：角色盯着饼干 → 角色把饼干捧到胸前
- 画面提示草案：蓝发角色双手捧起桌上的饼干，中近景，缓推构图，屏幕光照亮侧脸。
- 视频简版草案：蓝发角色捧起饼干，中近景，镜头缓慢推进，真实手部动作。
- 动作/运镜草案：镜头缓慢向前，角色双手从桌面抬起并捧住饼干。
- 可行性：draft_ready

### 镜头 3 · 10.0–15.0 秒

- 画面：同一房间，饼干靠近嘴边
- 人物/动作：蓝发角色 / 咬住饼干
- 景别：近景
- 运镜：固定（宿主观察）
- 转场：硬切（宿主观察）
- 首尾帧：饼干靠近嘴边 → 角色咬住饼干
- 提示词：暂不展开。先复核镜头边界或拆出内部子镜。
- 可行性：review_required

### 镜头 4 · 15.0–20.0 秒

- 画面：同一房间，角色表情变化
- 人物/动作：蓝发角色 / 咬出缺口后得意
- 景别：特写
- 运镜：固定（宿主观察）
- 转场：硬切（宿主观察）
- 首尾帧：饼干完整 → 饼干出现缺口，角色得意
- 画面提示草案：蓝发角色咬出缺口后得意，特写，屏幕冷光，表情清晰。
- 视频简版草案：蓝发角色咬出饼干缺口后露出得意表情，特写，固定机位。
- 动作/运镜草案：角色咬下后嘴角上扬，眼睛看向镜头，动作停住。
- 可行性：draft_ready

### 镜头 5 · 20.0–25.0 秒

- 画面：同一房间，角色突然紧张
- 人物/动作：蓝发角色 / 被抓包后瞪眼脸红
- 景别：近景
- 运镜：固定（宿主观察）
- 转场：闪白后硬切（宿主观察）
- 首尾帧：角色停顿 → 角色瞪眼脸红
- 画面提示草案：蓝发角色被抓包后瞪眼脸红，近景，屏幕冷光，情绪转折。
- 视频简版草案：蓝发角色突然瞪眼脸红，近景，固定机位，情绪从停顿转为紧张。
- 动作/运镜草案：角色先停住，随后眼睛睁大、脸颊泛红，尾巴竖起。
- 可行性：draft_ready
