# Teaching Video Profile

Use when the reference is a course, lecture, tutorial, or explainer.

Required observations:

- transcript or subtitles
- chapter and topic boundaries
- examples, demonstrations, and exercises
- screen/camera composition
- speaker and visual aid usage

Professional output:

- lesson structure and information hierarchy
- reusable explanation patterns
- source timestamps and evidence
- production checklist

Separate teaching correctness from visual editing. A clean edit does not prove the lesson is correct.
