# Comic Drama Profile

Use when the reference is a comic drama, animation, or AI-generated narrative short.

Required observations:

- shot boundaries and durations
- character identity anchors
- scene and prop anchors
- camera movement per shot
- transition type per shot
- action start and end state
- first and last frame intent
- dialogue, subtitles, sound, and editing strategy

Professional output:

- structural feasibility
- optional asset preparation checklist (not an analysis gate)
- shot plan
- first/last frame and motion prompt templates
- continuity and QC checklist

Never present humor, net sense, personality, or virality as measured. Never invent camera movement or character identity without host evidence.
