# 征集 AIGC / 漫剧视频人工标注样本

> 这是一份可直接发布到论坛、社群或视频评论区的征集文案。目标是建立真实样本基准，不要求维护者先手工标注全部视频。

## 标题建议

**征集 AIGC 漫剧分析样本：一起把开源视频拆解 Skill 校准得更准**

## 正文

我在维护一个开源的 AIGC / 漫剧视频逆向拆解 Skill，主要做镜头、切点、节奏、运镜、转场和首尾帧的证据化分析。

目前代码能力和测试已经有了，但缺少真实视频的人工标注样本。希望大家帮忙提交几条自己有权使用的漫剧或 AIGC 短片，一起建立公开的校准集。

### 你可以提交什么

一条视频即可，不需要一次提交很多。最好是你自己有权使用、转载或分析的视频。

请提供：

1. 视频链接或可公开访问的样本；
2. 时长、画面比例、分辨率和大致来源；
3. 人工切点时间；
4. 每个镜头的运镜类别；
5. 每个镜头的入场转场类别；
6. 是否允许公开使用这条样本做校准；
7. 如果有，附一张联系表或关键帧。

### 人工标注格式

切点示例：

```text
5.0, 10.4, 16.8, 23.1
```

逐镜示例：

```text
镜头 1：固定，硬切
镜头 2：缓慢推近，硬切
镜头 3：固定，叠化候选
```

如果只能标切点，也可以先提交；运镜和转场可以留空。

### 重要要求

- 不要把工具输出当成人工答案；
- 不要提交没有授权的完整影视视频；
- 不要上传 Cookie、账号、私密链接或个人信息；
- 可以不公开原视频，只提交切点和少量经过授权的证据帧；
- 标注不必完美，能明确说明依据即可。

### 提交方式

请在 GitHub 仓库的 Benchmark / Compatibility issue 中提交，或按维护者提供的论坛帖格式回复。

建议标题：

```text
[Sample] AIGC漫剧 · 时长 · 画面比例
```

每一条真实样本都会帮助判断：切点是否准确、运镜是否稳定、转场是否容易误判，以及报告是否存在过度推断。
